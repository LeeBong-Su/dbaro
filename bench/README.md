# bench — 성능 기준 측정

사람이 "즉시"라고 느끼는 기준은 대략 100ms다. 아래 수치를 처음부터 측정 항목으로 두고 CI에서 매번 확인한다.

| 항목 | 목표 |
|---|---|
| 키 입력 → 화면 반영 | 16ms 이내 (60fps 한 프레임) |
| 자동완성 팝업 | 100ms 이내 |
| DB 응답이 온 뒤 첫 행 표시 | 100ms 이내 |
| 결과 그리드 스크롤 | 60fps 유지 |
| 앱 실행 → 입력 가능 | 2초 이내 |

한글 입력 회귀 테스트도 여기에 둔다: 한글 조합 중 자동완성 팝업, 세로 커서(블록 선택) 편집, 한글이 섞인 줄의 커서 이동.
