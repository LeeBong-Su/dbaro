# protocol — 앱과 엔진 사이 통신 규약

## 전송 통로: 표준 입출력 (1안)

앱이 `QProcess`로 엔진을 띄우고 엔진의 표준 입력·출력으로 메시지를 주고받는다.
VS Code와 언어 서버(LSP)가 쓰는 방식과 같다.

- 포트를 열지 않으므로 방화벽과 보안 문제가 없다.
- Windows에서 Qt의 `QLocalSocket`은 named pipe를 쓰고, Java의 로컬 소켓은 AF_UNIX라 서로 바로 맞지 않는다.
  표준 입출력은 모든 OS에서 같은 방식으로 동작한다.
- 엔진의 표준 출력은 프로토콜 전용이다. 로그는 표준 오류로 보낸다.

## 메시지 (미정)

- 프레임: 길이를 앞에 붙인 바이너리 프레임
- 제어 메시지(연결, 실행, 취소, 페이지 요청, 메타데이터 요청): Protobuf 또는 MessagePack
- 결과 페이지: Arrow IPC 등 컬럼 단위 바이너리 형식
- 결과는 한 번에 보내지 않는다. 처음 약 500행을 보내고, 앱이 스크롤하면 다음 페이지를 요청한다.

메시지 정의 파일은 형식을 정한 뒤 이 폴더에 둔다.
